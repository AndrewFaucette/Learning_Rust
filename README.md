# Project Title (Update)

This is a repository with all the projects I create to learn the basics of the Rust programming language.

## Instructions for Build and Use

Steps to build and/or run the software:

1. For all projects other that "hello_world" run `cargo build` to build the code (or you can just find and run the executable in the `target` folder)

Instructions for using the password manager:

1. When you run the code you will have 4 options: Access a password, add a password, remove a password, and exit.
2. First add passwords by selecting option 2 and inputting account names and passwords.
3. You can view the passwords saved using option 1, then select the account you want to view the password for.
4. You can remove a password with option 3.
5. Exit the program by selecting option 4.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:
